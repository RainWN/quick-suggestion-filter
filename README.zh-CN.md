# Quick Suggestion Filter

English document: README.md

Quick Suggestion Filter 是一个 VS Code 扩展，支持使用键盘按分类快速筛选原生代码补全结果。

## 分类

全部 / 变量 / 方法 / 代码段 / 关键字 / 枚举 / 类型 / 其他

## 命令

| 命令 | 说明 |
| --- | --- |
| `Quick Suggestion Filter: Trigger Filtered Suggestions` | 打开带分类筛选的补全 |
| `Quick Suggestion Filter: Hide Suggest And Tabs` | 隐藏补全框和页签栏 |
| `Quick Suggestion Filter: Select Previous Category` | 切换到上一个分类 |
| `Quick Suggestion Filter: Select Next Category` | 切换到下一个分类 |

## 默认快捷键

| 按键 | 操作 |
| --- | --- |
| `PageUp` | 上一个分类（页签栏可见时） |
| `PageDown` | 下一个分类（页签栏可见时） |
| `Escape` | 隐藏补全框和页签栏 |
