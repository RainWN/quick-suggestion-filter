# Quick Suggestion Filter

中文文档: README.zh-CN.md

Quick Suggestion Filter is a VS Code extension that lets you filter native code completions by category using the keyboard.

## Categories

- All / Variable / Method / Snippet / Keyword / Enum / Type / Other

## Commands

| Command | Description |
| --- | --- |
| `Quick Suggestion Filter: Trigger Filtered Suggestions` | Open suggestions with category filter |
| `Quick Suggestion Filter: Hide Suggest And Tabs` | Hide the suggest widget and tabs bar |
| `Quick Suggestion Filter: Select Previous Category` | Switch to the previous category |
| `Quick Suggestion Filter: Select Next Category` | Switch to the next category |

## Default Keybindings

| Key | Action |
| --- | --- |
| `PageUp` | Previous category (when tabs bar is visible) |
| `PageDown` | Next category (when tabs bar is visible) |
| `Escape` | Hide suggest widget and tabs bar |
